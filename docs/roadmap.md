# Development roadmap (post v1.2)

Completed educational modules: v1.0 FASTQ QC / trimming, v1.1 review of fictional
preclassified viral read summaries, and v1.2 basic ungapped comparison of actual
invented sequences against invented references (with cross-reference ambiguity).

Potential next steps (not implemented):
1. Adapter-aware trimming and realistic synthetic quality profiles.
2. Gapped/local alignment and SAM/BAM interpretation using established tools.
3. Database provenance, host subtraction, and reference versioning.
4. Simulated truth-set precision/recall and edge-case evaluation.
5. Reproducible workflows and more comprehensive technical verification.

No real pathogen detection, clinical reporting, or GMP validation is implied.
